# v1.1.7

## 更新内容

- 合并sub2api 0.2.10版本
- OpenAI OAuth/Codex 账号的 HTTP Responses 客户端可按账号面板既有 WSv2 开关/模式使用 WebSocket 上游，网关仍返回 SSE/JSON，客户端无需更换协议。API Key 自定义中转站的 HTTP 入站保持 HTTP 上游；其他平台不变。账号/全局强制 HTTP 与禁用 WS 仍有效，独立 compact 端点保持 unary HTTP。协议切换不保证模型首输出更快。
- Codex OAuth/SetupToken 的 Responses WebSocket 握手固定使用官方当前 WSv2 Beta `responses_websockets=2026-02-06`；API Key 兼容路径仍按协商协议保留旧兼容值。账号隔离、turn-state 与连接池安全边界不变。
- 收敛 Codex WS 握手：保留官方条件头（window、parent-thread、subagent、memgen、timing metrics），将完整 `tool_namespaces_info` 留在帧内 `client_metadata`，不塞入 HTTP Upgrade 头；最终仍剥离 `session_id`、`conversation_id`、`x-codex-installation-id` 和未经配置的 attestation。
- 新增 OpenAI HTTP Responses 按请求/账号/尝试编号关联的 `openai.forward_timing` 日志：连接获取、请求发送、上游首响应字节及响应头、首个有效输出事件、首次有效输出 Flush 返回。只记录阶段与耗时，不记录正文、凭据或上游 URL；Flush 表示本地写入边界，不等于客户端已收到，传输未触发的回调不补造时间。重试、缓存、并发及流式行为保持不变。
- 修复 OpenAI Responses 流式请求在等待上游 HTTP 响应头及首个完整事件期间的下游保活；心跳不拆分 SSE 事件、不计入语义输出，跨重试累计扣除心跳字节。首拍前保留 HTTP 错误状态，首拍后使用流内失败事件；保活不代表上游推理提速。
- 移除 OpenAI 容量降载（`server_is_overloaded` 等）的请求级早退：命中账号配置的 `temp_unschedulable_rules` 后照常写入模型级冷却（例如 503 + overloaded → 30 分钟），同账号有界重试与切号流程保持不变。
- 降智检测改为账号原生探测：直接使用目标账号自身的上游凭据发送 ModelTrace 探测，管理员不再选择计费 Key，探测也不再回环进公开网关。
- 降智检测模型列表新增 `gpt-6.1-sol`。指纹库暂无该分类时，命中同系列参考类判「不确定」，命中其它模型判「疑似降智」，避免健康账号被误判。
- 新增「自动降智检测」：可配置检测间隔、封锁时长与检测模型，默认关闭。判定降智的账号临时停调并在到点复查，仍降智则续期，恢复正常后自动解除本功能写入的封锁；探测失败既不加封也不解封。
- 自动降智检测按请求模型保留实际预测模型、概率、解析数量和失败原因，并在账号状态及本功能的封锁原因中保存；临时停调详情展示请求模型 → 预测模型与概率。旧记录不补造预测，判定阈值和其它来源的封锁规则不变。
- 请求审计改为数据库管理 ID、关联关系与正文路径；正文按请求/响应独立保存为冷 JSON，取消启动全量扫描、正文索引恢复和每次写入时的整会话重写。迁移 249 为旧审计数据清空切换，不自动导入历史正文。
- 新增请求历史的精确前缀增量存储：同用户/API Key、同会话且字节校验匹配时只保存新增后缀；修改、压缩或截断历史时保存完整快照。查看和导出验证并重建完整记录，保留全部新增工具结果与消息；迁移 250 保持已有冷快照可读。
- 大型请求审计会话改为请求窗口前后翻页；窗口内消息与超长正文分段渲染，折叠推理/系统正文延迟挂载，避免加载下一组时无限累积 DOM。数据库仅加载窗口及前驱 ID，详情读取单请求；筛选条件和后台完整历史导出保持不变。
- 调整 Codex 请求序列化，保留原始顶层字段顺序；保留已通过来源检查的客户端 turn-state，并限制票据 Cookie 为基础设施 Cookie。
